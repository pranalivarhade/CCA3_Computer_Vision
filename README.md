# CCA3 – Computer Vision Assignment

## Project Overview
This project implements various Computer Vision techniques using Python, OpenCV and related libraries.

The assignment covers four major areas:

1. Image Processing – Image restoration and segmentation.
2. Feature Extraction – SIFT feature detection and feature matching.
3. Object Detection – Haar Cascade and YOLO-based object detection.
4. Motion Estimation – Frame Differencing, GMM Background Subtraction, Dense Optical Flow and Contour-Based Motion Detection.

## Technologies Used
- Python
- OpenCV
- NumPy
- Matplotlib
- Scikit-image
- Ultralytics YOLO
- Google Colab

## Project Structure

- `CCA3_Computer_Vision.ipynb` – Complete source code and execution results.
- `outputs_compressed.zip` – Compressed output images and processed results.
- `requirements.txt` – Required Python libraries.
- `README.md` – Project documentation.

## Execution Instructions

1. Download or clone this GitHub repository.
2. Install the required Python packages using:

   `pip install -r requirements.txt`

3. Open the Jupyter Notebook in Google Colab.
4. Upload the required input photograph and video.
5. Update the input file paths if necessary.
6. Run the notebook cells sequentially.
7. View the generated output images and results.

## Output Files

The compressed output archive contains the generated results for all four tasks, including processed images, feature matching results, object detection images, motion detection results and extracted video frames.

## Input Dataset

The original photograph and video used for the assignment are stored in Google Drive.
